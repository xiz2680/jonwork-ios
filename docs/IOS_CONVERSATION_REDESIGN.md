Export content is cleared on invalidation, and delayed share presentation repeats admission. Sign-out removes generated temporary exports and stops speech. Dynamic Type, accessibility labels and 44-point composer targets are retained; Reduce Motion stops shimmer/loading/background motion while ordinary animation remains available.

Pi extension flags/defaults are scoped to an authenticated **authorization lifetime**, not to an asserted user identity. Installation client ID is not a principal. Every fresh authorization replacement purges earlier preferences, drafts and bindings; the shared epoch fences old domain callbacks and credential writes/deletes. Current/default model entries cannot select arbitrary stale models. Text drafts are transient; attachment drafts are cleared with editor/transient state. Cold-restart draft persistence is not introduced.

## Authentication and identity isolation

Discovery centrally validates normalized scheme, host and effective port for credential, token and revocation endpoints before authentication, refresh or revocation. All OAuth POST redirects are refused, including same-origin and 303/307/308. Authenticated Pi command/upload/SSE requests also refuse redirects before a target request can be made. Browser authorization redirects remain part of the explicit trusted browser flow. Debug diagnostics contain phases and numeric error/status classifications only; release diagnostics are disabled.

Pi sign-out/unbind clears transient rendered rows and notifies former bindings. Delayed mutation snapshots must match the captured binding, generation and current reducer revision/cursor before replacing state. Fresh authorization advances a shared credential epoch so noncooperative old responses cannot recreate old account state.

Home local pin/favorite flags use hashes of the verified subject, scope type/ID, workspace, generation, origin and session. Old clients cannot read/write these after the shared epoch changes. Logout purges origin flags; cached restoration of the same verified identity may reuse them. These extensions do not mutate Home sessions.

Home uses exact `home.read` and a separate Keychain namespace; `pi.gateway` tokens are never treated as Home authority. Home restores through its own handshake without Pi repositories/connect. Its verified subject, scope, workspace and generation form the server identity binding. A weak per-origin client authority synchronously clears all live Home clients and cancels tracked old reads/browser work before a logout begins discovery/revocation. Every late save and cleanup is guarded by the captured epoch, including handshake failures and 401/403/409. Remote revocation failure does not restore local authority. Home history keeps the cleared surface visible with the actual revocation error instead of silently dismissing it.

Home event outcomes are typed at the domain layer. Explicit terminal errors and authoritative failed/rejected/cancelled snapshots override saved results. Recoverable tool/Agent errors do not poison a successful result when persisted events omit DONE. Outline previews and unresolved `tool_metadata.ask_user` remain waiting. Actual retry turn IDs separate outcomes while retaining earlier trace events and branch graph data.
