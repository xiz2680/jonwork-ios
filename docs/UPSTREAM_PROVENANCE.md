# Upstream provenance

Jonwork derives from [Lakr233/FlowDown](https://github.com/Lakr233/FlowDown). The product foundation was recorded as FlowDown 4.9.2 in Linear XIZ-112 and imported as a separate Jonwork root commit, without the upstream Git history.

The original AGPL-3.0 LICENSE, author headers and third-party notices remain. Renaming application modules, targets and workspace does not change the inherited source license or original authorship.

The upstream name, icon and artwork are proprietary. Jonwork uses its owned name, bundle IDs and J artwork. The preserved `LandingPage/` website, screenshots and marketing links are reference material, not Jonwork's distribution website or submission screenshots. Do not deploy that source as Jonwork marketing or package proprietary upstream imagery.

Historical storage paths, backup magic, CloudKit zones, model-exchange constants and online-test credential filenames remain where changing them would lose data or break format compatibility. They are compatibility identifiers rather than product branding.

Third-party package origins/revisions remain unchanged. Use `make scan-license` for reviewed dependency changes and review generated notices before committing.
